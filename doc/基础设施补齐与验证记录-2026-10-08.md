# 业务实施前基础设施补齐记录

## 已完成

| 项目 | 实现 |
| --- | --- |
| 响应兼容 | ApiResult 默认值、ok/error 重载、链式 put 和顶层扩展字段 |
| 身份名称 | Identity 实现 Principal，getName 返回 username；保留用户 ID 和学院 |
| 身份适配 | JdbcIdentityResolver 参数化只读 SELECT，实时读取启用用户/角色/权限，不查询密码或复用旧缓存 |
| 一致读取 | 身份权限查询使用独立只读可重复读事务和查询超时 |
| 作息契约 | 节次保留 String 读取方式，验证时间；恢复与旧配置等价的排序规则指纹 |
| SDK 资源 | DoorAccessRuntime 管理真实 SDK 单例、监听器和自有线程组，停机释放；默认关闭 |
| 字段填充 | MyMetaObjectHandler 注入上海 Clock，兼容 Date/LocalDateTime，安全跳过 ParamMap |
| MyBatis 配置 | 注解逻辑删除值与旧工程一致，不将业务 status 全局映射为删除字段 |
| Redis 锁 | 字符串令牌、Lua 比较释放/续期、永久失效租约、共享续期线程和容器停机释放 |
| MySQL 锁 | 同事务连接、事务后释放、同名去重、释放失败终止连接，保留共享锁名 |
| 生产就绪 | sharedAuth 与 sharedSchema 纳入 prod readiness；表检查只读，不运行迁移 |
| 后台配置 | 分离考试刷新/对账/命令超期开关，默认 false；校验门锁任务/Quartz 与 SDK 启用依赖 |
| 运维入口 | 构建/启动 JDK 21 检查、外部配置目录支持、环境变量模板 |

作息覆盖起止日期保留新工程 LocalDate 类型；原业务 String 日期调用点仍需在业务迁移时适配。
SDK 没有公开按实例设置线程数的 API，已移除原先未接入 SDK 的独立线程组和无效线程数配置。

## 验证

- 合计 42 项测试（common 2、server 40）：失败 0、错误 0、跳过 0。
- 身份读取：H2 内存表验证学院、真实用户名、停用用户/角色/菜单、实时权限变更与缺表拒绝。
- 认证集成：原始 JWT、Redis 会话编码/撤销模拟、角色和 LOCK_ONLY、Authentication.getName。
- SDK：实际初始化并关闭 ConnectorAllocator 与两个 SDK 线程组；关闭后可重新创建；无设备连接或动作。

- 产物包含 door-access-io-1.0.jar、Spring Boot 3.5.7 和两个 Lua；不含 H2、测试类或测试探针 Controller。

验证限于基础设施、内存身份数据库、模拟依赖以及无设备连接的实际 SDK 生命周期。
