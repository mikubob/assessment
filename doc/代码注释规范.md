# Java 代码注释规范

独立工程沿用现有 assessment 项目的中文 Javadoc 风格。

- 类、接口、内部类和 record 用多行 Javadoc 说明职责及必要的使用边界。
- 成员字段用多行 Javadoc 说明用途；配置项写明时间单位、启用条件或默认行为。
- 构造器和方法说明实际行为；参数使用 @param，非 void 返回值使用 @return。
- 必要的失败条件使用 @throws，内容与实际代码一致；不为捕获后处理的异常添加不真实的抛出说明。
- record 的组件在 record 类型注释中使用 @param 说明。
- 保留已有的关键说明和实现步骤注释，不仅重复类名或方法名。
- 继承方法可使用具体说明或 {@inheritDoc}；Bean 创建方法写明配置目的和返回对象。
- 不填写推测的作者、日期或版本信息；代码中的真实敏感配置不写进注释。
- 注释位于声明及其注解之前，使用 UTF-8 保存。

方法注释格式：

    /**
     * 检查请求令牌是否与共享 Redis 中的当前会话令牌一致
     *
     * @param userId 真实用户 ID
     * @param token 请求令牌
     * @return 令牌仍为当前会话时返回 true
     * @throws org.springframework.dao.DataAccessException 共享 Redis 会话读取失败
     */

当前已有的生产和测试 Java 文件均已按此格式补齐声明注释。

本次已核对 51 个 Java 文件、340 处显式声明，Javadoc 及参数/返回值标签无缺失；
去除注释后的代码词法及字符串内容保持一致。JDK 21 下编译、Spring Boot 3.5.7 打包
和 Javadoc 生成通过。Javadoc 工具对编译器隐式生成的默认构造器给出提示；
本次没有为消除该提示新增无业务意义的构造器。
